About the JAXA P-Tree system


Prepared by Earth Observation Research Center (EORC),
            Space Technology Directorate I,
            Japan Aerospace Exploration Agency (JAXA).

Aug.31,2015: Released.

********************************************************************************

The JAXA P-Tree system provides the Himawari Standard Data, which is provided 
by the Japan Meteorological Agency, and the geophysical parameter data, which
is estimated from the Himawari Standard Data by JAXA, in near-real-time. 

********************************************************************************

# Structure of FTP Directories

## Himawari Standard Data

 /jma/

## Himawari Geophysical Parameter Data

 /pub/


NOTE: Detailed description of data can be found at each directory.
